Dev panel — drive the feed by hand

–

Start match creates a match under the id you type (or a generated one if the field is empty) with random teams and prices on the provider simulator, which streams it to the feed worker like any provider traffic, so the rest of the system cannot tell the two apart. Use this instead of waiting for the scripted loop's ~4 second bettable window.
Auto-drift makes the simulator itself keep moving prices, waiting a random gap in the given range (10 ms–60 s) each time — a real feed does not tick on a metronome. Equal min and max give a fixed cadence. It runs only while the dev match is the event being tracked with live updates confirmed, and stops on settlement, on a dropped or unconfirmed stream, or when you track something else. The page renews it every 2 s; close the tab and the simulator stops it within 5 s — a demo should never leave traffic running unwatched.
